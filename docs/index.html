How it works

  1. Drop in the clip that will not play.
  2. Drop in any clip from the same camera, same settings, that does play. Cinesalve reads how your camera writes a file, so it can rebuild the damaged one to match.
  3. Watch the recovered footage. Save it when you are happy.

Nothing is uploaded. Your footage never leaves your Mac, there is no account, and the app works with the network switched off. Damaged recordings are often the only copy of something private, and they should not have to travel to a stranger’s server to be read.

How exact is the recovery

Exact, on everything measured so far. The test compares a repaired file against the original it was cut from and counts a frame as recovered only when it lands at the same position and the same size the camera wrote. A frame decoded from a repaired file is byte‑for‑byte identical to the same frame in the original.

What it does not do yet

Every figure above comes from files encoded on a computer, not from a real camera. Cinesalve has not yet been tested against footage from a DJI, GoPro, Sony, Canon or iPhone, and those write containers with quirks of their own. If you have a damaged clip from real hardware, send it and you will get a straight answer about whether it can be recovered, before any money changes hands.

It handles H.264 and HEVC video with AAC audio in MP4 and MOV containers, which is what consumer and prosumer cameras record. It does not handle ProRes, MXF or AVI. It repairs recordings that were interrupted, which is the common failure; it cannot invent footage that was never written to the card.

About one audio frame in a hundred is still placed imperfectly, which can leave a faint tick. Video is exact.
